# Strukturen

Ein Visual-Studio-Projekt zur Einführung in die Definition und Verwendung von Strukturen (`struct`) in der C#-Programmierung.

## Beschreibung

Das Projekt **Strukturen** beschäftigt sich mit den Grundlagen der Verwendung von Strukturen in C#. Strukturen ermöglichen es, mehrere zusammengehörige Daten in einem eigenen Werttyp zusammenzufassen.

Im Mittelpunkt stehen die Definition, Initialisierung und Verwendung von Strukturen sowie deren Unterschiede zu Klassen innerhalb der objektorientierten Programmierung.

## Funktionen

- Definition und Verwendung von Strukturen (`struct`)
- Zusammenfassung zusammengehöriger Daten
- Deklaration und Initialisierung von Strukturvariablen
- Zugriff auf Felder und Eigenschaften
- Grundlagen der Werttypen in C#
- Verständnis der Unterschiede zwischen Strukturen und Klassen

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/Strukturen.git
   ```

2. Die Datei `Strukturen.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
